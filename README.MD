# Практическая работа №10 — анализ отзывов (ML + Flask)

## Что нужно преподавателю

1. **Датасет** (не в репозитории из‑за размера): скачать и положить в корень проекта файл  
   `rotten_tomatoes_movie_reviews.csv`  
   *https://www.kaggle.com/datasets/andrezaza/clapper-massive-rotten-tomatoes-movies-and-reviews?select=rotten_tomatoes_movie_reviews.csv*
2. Установить зависимости и запустить приложение (см. ниже).

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Открыть в браузере: **http://127.0.0.1:5000**

Первый запуск может занять 1–2 минуты (обучение моделей и заполнение БД).
